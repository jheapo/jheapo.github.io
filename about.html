GCSee, JHeapo, and JScrub: Three tools. One goal. Help you understand how your Java application uses memory and uncover opportunities to reduce its memory footprint.

These tools were built on years of experience diagnosing Java memory problems in production. GCSee helps you identify GC tuning opportunities from production GC logs. JHeapo analyzes heap dumps far too large for conventional tools, making it practical to investigate the largest Java applications. JScrub pseudonymizes sensitive application data, allowing heap dumps to be shared safely without compromising the quality of the analysis.

The tools are only half the story. We understand how the Java Virtual Machine works, so your team doesn't have to. Whether you're investigating a production incident, diagnosing a JVM crash, chasing down a memory leak, or reducing infrastructure costs, we can help. Our analysis service turns your data into concrete findings, actionable recommendations, and a clear path forward.

Kirk Pepperdine is a Java Champion, JVM performance consultant, with decades of experience solving Java performance regressions. He is the creator of GCSee, JHeapo, and JScrub.
